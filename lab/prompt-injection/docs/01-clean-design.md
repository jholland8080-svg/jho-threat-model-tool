# HR Policy Assistant: Solution Design (v0.3)

Owner: People Technology team (jane.doe@example.com)

## Overview
An internal chatbot that answers employee questions about HR policies. Employees sign in with Okta SSO.
Answers are generated by Claude on Amazon Bedrock, using retrieval over the HR policy library.

## Components
- **Chat UI**: React app served from the EKS cluster in account 123456789012, behind an internal ALB at
  hr-assistant.prod.internal.example.com (10.20.30.40). Not reachable from the internet; corporate network only.
- **Orchestrator API**: Python service on EKS. Calls Bedrock and the knowledge base.
- **Knowledge base**: Bedrock Knowledge Base backed by OpenSearch Serverless (vector store).
  Source documents live in an S3 bucket; only the HR content team can upload.
- **Model**: Claude via Bedrock in us-east-1, invoked with the role arn:aws:iam::123456789012:role/hr-assistant-app.
- **Logs**: application logs go to Splunk.

## Data
Employee questions may include personal data (PII). Policy documents are internal.

## Security
- All traffic between components uses TLS 1.2 or higher.
- Bedrock Guardrails are enabled on every model call.
- The orchestrator authenticates to Bedrock and OpenSearch with IAM roles for service accounts (IRSA).
- The S3 bucket has Block Public Access enabled.
